# Rosário Montfort

Página de aviso de rosariotradicionalmontfort.online.

O antigo app web foi aposentado: o Rosário Montfort agora é um aplicativo nativo, que chega em breve à Google Play. Novidades e contato no Instagram [@guardioes.fe](https://www.instagram.com/guardioes.fe/).

O código do app web antigo continua no histórico do git (último commit com ele: 05e1367).

Arquivos mantidos:
- `index.html` e `404.html`: a página de aviso.
- `privacidade/`: política de privacidade, usada pela ficha da Google Play.
- `.well-known/assetlinks.json`: vínculo do domínio com o app Android.
- `sw.js`: apaga o cache do app antigo nos aparelhos de quem o tinha instalado.
